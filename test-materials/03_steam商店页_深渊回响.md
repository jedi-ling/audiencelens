# 深渊回响
### 一场关于记忆与深渊的银河城式探索

---

**关于游戏**

《深渊回响》是一款黑白水墨风格的银河城探索游戏。你扮演一名失忆的潜水员，
在一座沉入深海的古代都市中探索、战斗、拼凑破碎的记忆。每一次死亡都会
留下一段"回响"，成为下一次尝试中可以互动的幽灵线索。

**核心特色**

- 独创的"回响"死亡机制：死亡不是失败，而是叙事的一部分
- 手绘水墨美术风格，全程黑白配色，仅在关键剧情节点出现血红色点缀
- 非线性地图，8 种可习得能力驱动的箱庭解谜
- 无对话文本的叙事设计，靠环境与回响碎片讲故事
- 预计流程 12-15 小时，支持手柄与键鼠

**系统需求**

最低配置：
- 操作系统：Windows 10 64位
- 处理器：Intel i3-6100 / AMD FX-6300
- 内存：4 GB RAM
- 显卡：GTX 750 Ti / Radeon R7 260X
- 存储空间：需要 3 GB 可用空间

推荐配置：
- 操作系统：Windows 10/11 64位
- 处理器：Intel i5-8400 / AMD Ryzen 5 2600
- 内存：8 GB RAM
- 显卡：GTX 1060 / Radeon RX 580
- 存储空间：需要 3 GB 可用空间
