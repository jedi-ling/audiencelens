# 评估器：输入接地性（Input Grounding）

检查人格反馈是否引用了输入材料中的具体细节，而非给出泛泛之谈。

## 评分标准（1-5分）

### 5分 — 深度接地
每条证据都引用了输入材料中的具体内容，并标注了来源位置。无凭空编造的细节。

**通过示例：**
- "材料中明确提到'管理能量、电池、风险信用值和金钱'四种资源，但未说明风险信用值耗尽的后果，这可能导致玩家无法评估风险。"（引用了核心循环描述，指出信息缺口）
- "测试焦点要求'玩家是否理解为什么要轮换节点'，但核心循环描述中没有解释轮换的机制原因，存在认知断层。"（连接了测试焦点和核心循环）
- "目标平台为'移动端/小程序'，但核心循环涉及'管理四种资源'，小屏幕上信息密度可能过高。"（基于平台和机制的交叉推理）

### 4分 — 大体接地
大部分证据引用了具体材料，少数证据仅做泛泛描述。

**通过示例：**
- "游戏的核心循环有趣"（未引用具体内容）+ "赛博打工人主题与'7天KPI'目标的叙事一致性很好"（引用了具体内容）

### 3分 — 部分接地
约半数证据引用了具体材料细节，另一半是通用建议。达到最低通过线。

**勉强通过示例：**
- "游戏有潜力"（空泛）+ "移动端需要简化操作"（基于平台推断但未引用原文）+ "风险控制机制是亮点"（引用了测试焦点）

### 2分 — 多数空泛
大部分反馈是通用建议，仅偶尔提及项目名称或个别关键词。

**不通过示例：**
- "赛博拾荒者是一款有趣的游戏，建议优化用户体验"
- "核心循环需要更有深度"
- "移动端游戏要注意操作简化"

### 1分 — 完全脱离
反馈内容与输入材料无关，像是通用模板套用。甚至编造了输入材料中不存在的机制。

**不通过示例：**
- "游戏的多人联机模式很有趣"（材料中未提及联机）
- "开放世界探索是核心卖点"（材料中未提及开放世界）
- "建议增加PVP竞技场"（材料中无此方向）

## 评估方法

1. 提取每个 persona 输出中的 `evidence` 列表
2. 对每条 evidence 检查：
   - **直接引用**：是否包含输入材料中的原文或近义表述？
   - **来源标注**：是否标注了 `source_location` 或 `inference_level`？
   - **无幻觉**：`inference_level=direct` 的条目是否能在输入材料中找到对应？
3. 计算接地率：`直接引用条目数 / 总证据条目数`
4. 检查幻觉率：`无法在输入中定位的direct条目数 / direct总条目数`
5. 综合评分：
   - 接地率 ≥ 80% 且幻觉率 < 10% → 5分
   - 接地率 60-79% 且幻觉率 < 15% → 4分
   - 接地率 40-59% 且幻觉率 < 20% → 3分
   - 接地率 20-39% 或幻觉率 20-40% → 2分
   - 接地率 < 20% 或幻觉率 > 40% → 1分

## 关键失败条件

- 幻觉率 > 40%（超过40%的"直接"证据无法在输入中定位）→ 自动 1分
- 任何 persona 编造了输入材料中明确不存在的机制/功能/内容 → 该维度 ≤ 2分
- 所有 persona 的 evidence 列表为空 → 自动 0分
