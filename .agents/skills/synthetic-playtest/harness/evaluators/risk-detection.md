# 评估器：风险检测力（Risk Detection）

检查评审是否识别了关键风险（致命问题、交易破坏者），而非仅关注次要问题。

## 评分标准（1-5分）

### 5分 — 强风险检测
识别了致命级风险（showstopper），且为不同人格分段标注了分段特异性风险。风险描述包含具体影响和严重度。

**通过示例：**
- "致命风险：核心循环中'风险信用值'机制未说明耗尽后果，可能导致玩家无法理解游戏的核心决策张力。"
- "分段风险：核心系统型玩家可能因'7天生存'目标缺乏系统深度而快速流失。"
- "交易破坏者：移动端同时管理4种资源的信息密度可能超出小屏幕承载能力。"

### 4分 — 良好风险检测
识别了明确的阻碍和异议，包含严重度标注，但缺少分段特异性分析。

**通过示例：**
- "高严重度：新手引导未解释节点轮换的机制原因"
- "中严重度：赛博主题与KPI目标的叙事一致性待验证"

### 3分 — 基础风险检测
识别了一些风险，但多为通用风险，缺少致命级问题标注。达到最低通过线。

**勉强通过示例：**
- "游戏可能面临留存问题"（通用风险）
- "核心循环需要更多深度"（未说明为什么是风险）

### 2分 — 弱风险检测
仅识别了次要问题，未触及任何关键风险。

**不通过示例：**
- "UI颜色可以更协调"（次要）
- "文案可以更精炼"（次要）
- 完全没有提及核心循环、目标受众匹配、平台适配等关键风险

### 1分 — 无风险检测
报告中没有识别任何风险，或所有发现都是正面评价。

**不通过示例：**
- "游戏各方面表现优秀，没有明显问题"
- 所有 key_issues 的 severity 都是 "low"

## 评估方法

### 风险层级分类

对报告中每个 `key_issue`，按以下标准分类：

| 层级 | 定义 | 示例 |
|------|------|------|
| **致命（Showstopper）** | 不解决则产品无法上线或核心体验崩溃 | 核心机制无法理解、目标平台不兼容 |
| **高（Deal-breaker）** | 不解决则目标用户群大量流失 | 新手引导失败、价值主张不清晰 |
| **中（Objection）** | 影响部分用户体验但可容忍 | UI信息密度偏高、部分文案模糊 |
| **低（Minor）** | 锦上添花的改进 | 颜色微调、措辞优化 |

### 检查项

1. **致命风险覆盖**：是否识别了至少1个致命/高级别风险？
2. **severity 分布**：key_issues 中 high/critical 占比是否 ≥ 20%？
3. **分段风险**：是否有 persona 标注了该 persona 特有的风险？
4. **Top Blockers**：报告中是否有独立的"Top Blockers"章节？
5. **风险具体性**：风险描述是否包含具体影响而非泛泛而谈？

### 综合评分

| 条件 | 分数 |
|------|------|
| 识别致命风险 + 分段特异性风险 + Top Blockers章节 | 5分 |
| 识别高级别风险 + Top Blockers章节 | 4分 |
| 识别中级别风险，有severity标注 | 3分 |
| 仅识别低级别风险 | 2分 |
| 无风险识别 | 1分 |

## 关键失败条件

- 所有 key_issues 的 severity 为 "low" → 自动 1分
- 报告无任何负面发现 → 自动 0分
- 缺少 Top Blockers 章节 → 该维度 ≤ 3分
- 未识别输入材料中明显存在的致命风险（如弱概念的范围蔓延、平台不兼容）→ 自动 1分
