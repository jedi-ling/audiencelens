# AudienceLens Web — 产品需求文档 (PRD)

## 1. 产品概述

**AudienceLens Web** 是 AudienceLens 多代理玩家评审系统的 Web 应用版本。用户通过浏览器上传游戏素材，选择任务类型和 Persona 面板，系统自动运行多代理评审并生成结构化报告。

### 核心价值

- **零门槛**：无需安装 Python 或 Claude Code，浏览器打开即用
- **可视化**：Persona 面板、评审进度、报告结果全部可视化呈现
- **可分享**：生成可分享的报告链接，团队成员可协作查看

### 目标用户

1. **独立游戏开发者**：在发布前快速发现商店页/Demo/概念稿的问题
2. **小型发行商**：评估投资标的的市场表现潜力
3. **游戏设计学生**：学习多视角评审方法论
4. **社区运营者**：优化社区文案和更新公告

## 2. 功能需求

### P0 — MVP 核心功能

#### 2.1 评审创建页

- 选择任务类型（10种，含图标和说明）
- 上传评审材料（JSON/YAML 文件上传 + 手动填写表单）
- 选择 Persona Pack（8个 Pack 可选）
- 自定义面板（从 Pack 中勾选/取消 persona，显示行为轴雷达图）
- 一键启动评审

#### 2.2 评审进度页

- 实时显示每个 Persona 的评审状态（等待中/运行中/已完成/失败）
- 每个 Persona 完成后即时展示其输出摘要
- 交叉质询进度
- 聚合进度
- 预估剩余时间和成本

#### 2.3 报告展示页

- Executive Summary 卡片（主要建议、发布风险、证据质量）
- 共识/分歧可视化（立场分布饼图 + 分歧详情折叠面板）
- 优先修复项列表（可排序、可筛选 severity）
- Persona 视角卡片（每个 persona 的立场、证据、退出触发器、原声评价）
- 信息缺口列表
- 下一步真人测试建议
- 校准指标仪表盘
- 导出 JSON / Markdown / PDF

#### 2.4 Persona 浏览页

- 8个 Pack 的分类展示
- 每个 Persona 的详细卡片（行为轴雷达图、决策规则、退出/继续触发器）
- Persona 间对比功能（两个 persona 的行为轴对比雷达图）
- 搜索和筛选

### P1 — 增强功能

#### 2.5 历史记录

- 评审历史列表（时间、任务类型、目标、状态）
- 历史报告查看和对比
- 重跑功能（同一材料不同 persona 组合）

#### 2.6 团队协作

- 分享报告链接（只读）
- 团队空间（共享 Persona Pack 和评审历史）
- 评论和标注

#### 2.7 自定义 Persona

- 可视化 Persona 编辑器（拖拽行为轴滑块）
- 自定义 Persona 保存和复用
- Persona 校准建议

### P2 — 企业功能

#### 2.8 管理后台

- 用户管理（RBAC）
- 用量和成本监控
- 自定义 Persona Pack 管理
- 审计日志

## 3. 页面结构

```
/                           → 首页（产品介绍 + 快速开始）
/review/new                 → 创建评审
/review/:id                 → 评审进度 + 报告
/review/:id/report          → 完整报告
/personas                   → Persona 浏览
/personas/:id               → Persona 详情
/history                    → 历史记录
/settings                   → 设置（API Key、偏好）
```

---

## 4. 用户流程

```
首页 → 创建评审 → 选择任务类型 → 上传材料 → 选择面板 → 启动
                                                    ↓
                                              评审进度页（实时更新）
                                                    ↓
                                              报告展示页
                                                    ↓
                                         导出 / 分享 / 重跑
```

---

## 5. 非功能需求

| 需求 | 指标 |
|---|---|
| 首屏加载 | < 2s |
| 评审启动响应 | < 500ms |
| 实时进度更新 | WebSocket，延迟 < 1s |
| 并发评审 | 支持 10 个同时运行 |
| 数据持久化 | SQLite（MVP）/ PostgreSQL（生产） |
| 安全 | API Key 加密存储，评审数据隔离 |

## 6. 设计方向

**美学关键词**：深色科技感 + 游戏化元素

- **色调**：深色背景（#0a0a0f），霓虹绿/青色强调色（#00ff88 / #00d4ff），暖橙色警告色（#ff6b35）
- **字体**：JetBrains Mono（代码/数据）+ Noto Sans SC（中文正文）
- **动效**：Persona 评审运行为"扫描线"动画，报告生成为"数据流"渐入
- **图标**：像素风 + 线条图标的混合
- **布局**：左侧导航 + 主内容区，评审进度页为全屏仪表盘模式

---

## 7. 技术约束

- 前端：React + TypeScript + Tailwind CSS + shadcn/ui
- 后端：Python FastAPI（复用现有 src/runner/ 模块）
- 数据库：SQLite（MVP）
- 实时通信：WebSocket
- 部署：Docker Compose（前端 + 后端 + 数据库）
