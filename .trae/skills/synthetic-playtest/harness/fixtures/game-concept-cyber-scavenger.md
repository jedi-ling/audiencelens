# Cyber Scavenger（赛博拾荒者）

## 一句话描述

一款竖屏手游点击游戏，玩家扮演过度劳累的赛博员工，在不同AI平台节点上挖取算力代币，同时规避平台风控。

## 核心循环

点击不同AI平台节点生成算力代币，管理能量、电池、风险信用值和金钱四种资源。在7个游戏日内生存下来并达成周KPI。

## 目标平台

移动端 / 小程序

## 当前阶段

概念 + 早期UI原型

## 测试焦点

- 第一印象传达力
- 核心循环清晰度
- 风控机制张力
- 玩家是否理解为什么要轮换节点
- 讽刺幽默感是否足够

## 已有素材

- 核心循环流程图（4种资源的产出/消耗关系）
- 3张UI原型截图（主界面、节点选择、风控警告）
- 赛博打工人角色设定文档

## 已知风险

- 风险信用值机制可能过于复杂
- 7天生存目标与"打工人"主题的叙事一致性待验证
- 小程序平台对后台运行的限制
