# AudienceLens 评审质量量规

8维度评分标准，每维度1-5分。通过阈值：所有维度 ≥ 3分。

---

## 1. 行动可操作性（Actionability）

| 分数 | 标准 |
|------|------|
| 5 | 每条建议包含明确对象+动作+预期效果，P0/P1/P2优先级完整 |
| 4 | 大部分建议具体可操作，少数需追问细节 |
| 3 | 约半数建议可操作，另一半模糊 |
| 2 | 多数建议是方向性描述，缺少执行路径 |
| 1 | 无可操作建议，全是套话 |

**详细标准** → [evaluators/actionability.md](../evaluators/actionability.md)

---

## 2. 输入接地性（Input Grounding）

| 分数 | 标准 |
|------|------|
| 5 | 每条证据引用输入材料具体内容，标注来源位置，无幻觉 |
| 4 | 大部分证据引用具体材料，少数泛泛描述 |
| 3 | 约半数证据引用具体细节 |
| 2 | 多数反馈是通用建议，仅偶尔提及关键词 |
| 1 | 反馈与输入材料无关，或编造了不存在的机制 |

**详细标准** → [evaluators/input-grounding.md](../evaluators/input-grounding.md)

---

## 3. 人格差异化（Persona Differentiation）

| 分数 | 标准 |
|------|------|
| 5 | 每个persona关注点、论证逻辑和立场有本质差异，行为画像驱动 |
| 4 | persona间有清晰视角差异，少数议题趋同 |
| 3 | 有可辨识差异但较浅（措辞不同而非视角不同） |
| 2 | persona名字不同但行为几乎相同，仅措辞微调 |
| 1 | 所有persona产出几乎相同的反馈 |

**详细标准** → [evaluators/persona-differentiation.md](../evaluators/persona-differentiation.md)

---

## 4. 刻板印象检查（Stereotype Check）

| 分数 | 标准 |
|------|------|
| 5 | 所有判断基于behavior_profile，人口统计属性仅作弱修饰 |
| 4 | 绝大部分判断基于行为画像，偶有弱修饰但不影响核心逻辑 |
| 3 | 行为画像和人口统计属性交替使用，部分逻辑来源不明 |
| 2 | 多数判断以性别/年龄/地域/MBTI作为核心因果解释 |
| 1 | 大量使用人口统计刻板印象，行为画像形同虚设 |

**详细标准** → [evaluators/stereotype-check.md](../evaluators/stereotype-check.md)

---

## 5. 结构完整性（Structure Check）

| 分数 | 标准 |
|------|------|
| 5 | 所有必需章节完整且内容充实 |
| 4 | 所有章节存在，1-2个内容简略 |
| 3 | 缺少1个非关键章节，或2-3个内容简略 |
| 2 | 缺少2个及以上章节，或关键章节内容为空 |
| 1 | 缺少3个及以上章节，或缺少Disclaimer |

**详细标准** → [evaluators/structure-check.md](../evaluators/structure-check.md)

---

## 6. 校准诚实度（Calibration Honesty）

| 分数 | 标准 |
|------|------|
| 5 | 所有发现标注为假设，使用审慎语言，明确推荐真人验证 |
| 4 | 绝大部分使用审慎语言，偶有轻微过度自信 |
| 3 | 约半数审慎，另一半以确定语气陈述 |
| 2 | 大部分以事实语气陈述，缺少假设标注 |
| 1 | 声称预测真实成功/失败，将模拟发现当确定性结论 |

**详细标准** → [evaluators/calibration-honesty.md](../evaluators/calibration-honesty.md)

---

## 7. 风险检测力（Risk Detection）

| 分数 | 标准 |
|------|------|
| 5 | 识别致命级风险+分段特异性风险，含Top Blockers章节 |
| 4 | 识别高级别风险，含Top Blockers章节 |
| 3 | 识别中级别风险，有severity标注 |
| 2 | 仅识别低级别风险 |
| 1 | 无风险识别，或所有发现都是正面评价 |

**详细标准** → [evaluators/risk-detection.md](../evaluators/risk-detection.md)

---

## 8. 分段冲突度（Segment Conflict）

| 分数 | 标准 |
|------|------|
| 5 | 多维度有意义冲突，冲突指导产品决策 |
| 4 | 2-3处有意义冲突，但决策指导不够明确 |
| 3 | 至少1处有意义冲突 |
| 2 | 分歧仅存在于措辞或细节层面 |
| 1 | 所有persona在所有议题上完全一致 |

**详细标准** → [evaluators/segment-conflict.md](../evaluators/segment-conflict.md)

---

## 通过/失败判定

### 通过条件
- 所有8个维度 ≥ 3分
- 无关键失败条件触发

### 关键失败条件（任一触发即失败）

| 条件 | 涉及维度 |
|------|---------|
| 缺少 AI 生成免责声明 | 校准诚实度、结构完整性 |
| Priority Actions 无 P0/P1/P2 标注 | 行动可操作性、结构完整性 |
| 使用人口统计属性作为判断因果 | 刻板印象检查 |
| 报告未接地于输入材料 | 输入接地性 |
| 声称预测真实世界成功/失败 | 校准诚实度 |
| 所有 persona 无实质分歧 | 分段冲突度、人格差异化 |
| 未识别任何关键风险 | 风险检测力 |
