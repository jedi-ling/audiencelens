# 评估器：人格差异化（Persona Differentiation）

检查不同人格是否产出了真正不同的视角，而非换皮重复。

## 评分标准（1-5分）

### 5分 — 深度差异化
每个 persona 的关注点、论证逻辑和立场都有本质差异，差异来源于行为画像而非名字/标签。

**通过示例：**
- Steam 浏览型玩家关注胶囊图、标签、截图传达力
- 视觉优先型玩家关注氛围、UI一致性、截图可分享性
- 核心系统型玩家关注系统深度、可重玩性、数值平衡
- 毒舌评论者攻击过度宣传和原型感

### 4分 — 明确差异化
persona 之间有清晰的视角差异，但少数 persona 在部分议题上趋同。

**通过示例：**
- 3个 persona 中2个有独特关注点，1个与其他有部分重叠

### 3分 — 基础差异化
persona 之间有可辨识的差异，但差异较浅（措辞不同而非视角不同）。达到最低通过线。

**勉强通过示例：**
- 不同 persona 用不同措辞表达了相似观点，但至少在1-2个议题上有真正分歧

### 2分 — 浅表差异化
persona 名字不同，但行为几乎相同。仅措辞微调。

**不通过示例：**
- 每个 persona 都说"新手引导需要改善"
- persona 名字不同，但 key_issues 列表高度重合

### 1分 — 无差异化
所有 persona 产出几乎相同的反馈，像是同一个视角的复制品。

**不通过示例：**
- 所有 persona 的 key_issues 标题完全一致
- 所有 persona 给出相同的 primary_stance
- 所有 persona 的 scores 差异 < 0.5

## 评估方法

### 定量指标：Jaccard 距离

对每对 persona，计算其 `key_issues` 标题集合的 Jaccard 距离：

```
Jaccard距离 = 1 - |交集| / |并集|
```

- 距离 = 0：完全相同的议题集
- 距离 = 1：完全不同的议题集

**阈值：**
- 所有 persona 对的平均 Jaccard 距离 ≥ 0.5 → 差异化良好
- 平均 Jaccard 距离 0.3-0.49 → 差异化一般
- 平均 Jaccard 距离 < 0.3 → 差异化不足

### 定性检查

1. 读取每个 persona 的 `behavior_profile` 和 `decision_rules`
2. 检查该 persona 的 `key_issues` 是否与其行为画像逻辑一致
3. 检查是否有 persona 的反馈与其行为画像矛盾（如低耐心 persona 却要求更长的教程）

### 综合评分

| 条件 | 分数 |
|------|------|
| 平均 Jaccard ≥ 0.5 且行为画像一致 | 5分 |
| 平均 Jaccard 0.4-0.49 且行为画像基本一致 | 4分 |
| 平均 Jaccard 0.3-0.39 | 3分 |
| 平均 Jaccard 0.2-0.29 | 2分 |
| 平均 Jaccard < 0.2 | 1分 |

## 关键失败条件

- 任何两个 persona 的 key_issues 标题完全一致 → 该维度 ≤ 2分
- 所有 persona 的 primary_stance 相同且无分歧说明 → 自动 1分
- persona 的 scores 标准差 < 0.5（所有维度）→ 自动 1分
