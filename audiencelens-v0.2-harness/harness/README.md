# AudienceLens Harness

The Harness is a lightweight quality gate for AudienceLens skills.

It provides fixtures, rubrics, evaluators, and expected report requirements so humans or AI agents can test whether skill output is good enough.

## What the Harness Tests

1. Persona differentiation
2. Input grounding
3. Actionability
4. Segment conflict
5. Risk detection
6. Ethical persona use
7. Report structure
8. Calibration honesty

## Workflow

```text
Run skill on fixture
→ Generate report
→ Evaluate with rubric
→ Identify weak dimensions
→ Revise skill/persona/template
→ Re-run
```
