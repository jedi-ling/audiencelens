# AudienceLens Methodology

AudienceLens uses synthetic personas as a pre-validation tool.

It does not replace real playtests, surveys, interviews, analytics, or market research.

## Method

```text
Input material
→ extract assumptions
→ select persona panel
→ independent persona reviews
→ synthesize consensus and disagreement
→ run Harness quality check
→ produce action plan
```

## Why Harness matters

Without quality gates, synthetic audience systems easily become generic praise, shallow roleplay, stereotype-driven feedback, ungrounded hallucination, or non-actionable reports.
