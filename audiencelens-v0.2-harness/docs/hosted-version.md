# Hosted Version

AudienceLens open-source edition is for technical users who want full local control.

The AudienceLens hosted version is for creators who want one-click reviews without environment setup.

## Open-source edition

- local setup
- bring your own model key
- edit skills and personas manually
- Markdown/YAML output
- full control

## Hosted edition

- one-click game review
- no model key configuration
- visual reports
- report history
- version comparison
- private/public report sharing
- advanced persona panels
- platform integration
- membership / credit-based usage
