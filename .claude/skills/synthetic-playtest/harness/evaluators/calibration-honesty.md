# 评估器：校准诚实度（Calibration Honesty）

检查评审报告中的发现是否被正确标注为假设而非事实，标记过度自信的语言。

## 评分标准（1-5分）

### 5分 — 高度诚实
所有发现都被标注为假设或推断，使用审慎语言，明确推荐真人验证。不声称预测真实成功。

**通过示例：**
- "基于当前材料，该机制可能在新手引导阶段造成困惑，建议通过真人测试验证。"
- "persona 模拟表明风险信用值机制可能不够直观，但这需要实际玩家测试确认。"
- "本报告由 AI 人格生成，非真人研究数据。所有发现均为假设，需真人验证。"

### 4分 — 大体诚实
绝大部分发现使用审慎语言，偶有轻微过度自信但不影响整体判断。

**通过示例：**
- "这个设计会导致玩家流失"（过度自信）+ "建议通过A/B测试验证这一假设"（补救）

### 3分 — 部分诚实
约半数发现使用了审慎语言，另一半以确定语气陈述。达到最低通过线。

**勉强通过示例：**
- "玩家不会理解这个机制"（过度自信）+ "核心循环可能存在深度不足的问题"（审慎）的混合

### 2分 — 多数过度自信
大部分发现以事实语气陈述，缺少假设标注，但未直接声称预测成功。

**不通过示例：**
- "这个游戏一定会失败"
- "玩家绝对不喜欢这个机制"
- "这个设计注定行不通"

### 1分 — 严重过度自信
声称预测真实成功/失败，将模拟发现当作确定性结论。

**不通过示例：**
- "本报告可以准确预测市场表现"
- "经过AI分析，该产品将获得商业成功"
- "数据表明这个游戏注定失败"

## 评估方法

### 过度自信语言检测

在报告全文中搜索以下模式：

| 模式 | 正则 | 严重度 |
|------|------|--------|
| 绝对断言 | `一定会\|必将\|注定\|绝对\|毫无疑问` | 严重 |
| 事实声明 | `会导致\|将失败\|不可能成功\|玩家不会` | 中等 |
| 成功预测 | `预测.*成功\|市场表现.*确定\|准确预测` | 严重 |

### 审慎语言检测

正向检查以下模式是否存在：

| 模式 | 正则 |
|------|------|
| 假设标注 | `可能\|或许\|倾向于\|有可能\|表明.*假设` |
| 验证推荐 | `建议.*验证\|需要.*测试\|真人.*确认\|实际.*检验` |
| 免责声明 | `AI.*生成\|非真人\|模拟.*数据\|假设.*非事实` |

### 计算诚实度

```
诚实度 = 审慎语言条目数 / (审慎语言条目数 + 过度自信条目数)
```

### 综合评分

| 条件 | 分数 |
|------|------|
| 诚实度 ≥ 90% 且无严重过度自信 | 5分 |
| 诚实度 75-89% 且无成功预测 | 4分 |
| 诚实度 50-74% | 3分 |
| 诚实度 25-49% | 2分 |
| 诚实度 < 25% 或含成功预测声明 | 1分 |

## 关键失败条件

- 报告声称预测真实世界成功/失败 → 自动 0分
- 缺少 AI 生成免责声明 → 自动失败
- 将模拟发现作为事实结论呈现且无任何假设标注 → 自动 1分
- "本报告可以替代真人用户研究"类声明 → 自动 0分
