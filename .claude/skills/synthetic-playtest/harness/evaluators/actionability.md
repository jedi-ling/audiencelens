# 评估器：行动可操作性（Actionability）

检查评审报告中的建议是否具体可执行，而非空泛模糊。

## 评分标准（1-5分）

### 5分 — 精准可操作
每条建议都包含明确的对象、动作和预期效果。读者无需追问"怎么做"即可直接执行。

**通过示例：**
- "将商店页首屏截图替换为展示玩家在两个风险-回报节点间做选择的画面，以在3秒内传达核心决策玩法。"
- "在核心循环描述中增加'风险信用值耗尽后会发生什么'的说明，避免玩家误以为游戏只有收益没有惩罚。"
- "将'7天生存'目标改为'7天KPI冲刺'，与赛博打工人主题形成更强的叙事一致性。"

### 4分 — 大体可操作
大部分建议具体，少数需要追问细节。

**通过示例：**
- "优化新手引导流程，让玩家在前30秒理解风险信用值机制。"（缺：具体用什么方式引导）
- "增加节点轮换的视觉提示。"（缺：什么形式的提示）

### 3分 — 混合质量
约半数建议可操作，另一半模糊。达到最低通过线。

**勉强通过示例：**
- "改善UI布局"（模糊）+ "在能量条旁增加数字显示"（具体）的混合

### 2分 — 多数模糊
大部分建议是方向性描述，缺少具体执行路径。

**不通过示例：**
- "提升游戏体验"
- "优化视觉效果"
- "加强核心循环"
- "让玩家更有沉浸感"

### 1分 — 完全空泛
没有一条可操作的建议，全是套话。

**不通过示例：**
- "游戏有潜力，继续加油"
- "建议多打磨"
- "需要更多内容"

## 评估方法

1. 提取报告中所有 `suggested_fix` 和 `Priority Actions` 条目
2. 对每条建议按以下维度打分：
   - **对象明确**：是否指出了修改的具体元素（截图/文案/机制/流程）？
   - **动作明确**：是否使用了可执行动词（替换/增加/删除/修改）而非模糊动词（优化/改善/提升）？
   - **效果预期**：是否说明了修改后预期达到的效果？
3. 计算可操作建议占比：`可操作条目数 / 总条目数`
4. 综合评分：
   - 占比 ≥ 80% → 5分
   - 占比 60-79% → 4分
   - 占比 40-59% → 3分
   - 占比 20-39% → 2分
   - 占比 < 20% → 1分

## 关键失败条件

- Priority Actions 中没有任何 P0/P1/P2 优先级标注 → 自动 1分
- 所有建议都是"优化/改善/提升"类模糊动词 → 自动 1分
- 建议数量为 0 → 自动 0分
